# Ripple Journal

## 2026-08-12 - Split Runtime Fallback from Emergency Export Retirement

**Cross-cutting risk surface:** Industry Roles compatibility spans the shared
engine/store, protected API, candidate producers, Trade State, Analytics, and
deployment health. A later workflow-only change still invalidates dated
external-consumer continuity when the decision contract names workflows as a
relevant surface.

**Insight:** Retire automatic reads before removing an explicit recovery
projection. An empty canonical revision-zero seed preserves clean bootstrap,
while a natural producer window provides the evidence needed for a separately
authorized export removal. A successful process terminal is insufficient when
best-effort substeps can record error rows without failing the process; require
the critical substeps or their attributable outputs explicitly.

**Apply when:** A compatibility source is already absent but its read fallback
and recovery writer remain in shared runtime code.
